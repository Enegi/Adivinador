# Adivinador

## Autor
- Salcido Peralta Jorge Manuel

## Descripción
Un pequeño juego de java sobre adivinar numeros usando la terminal. Posee 2 modos de juego, Adivinado, en donde la maquina intenta adivinar el número que elijas de una lista de números y te muestra sus intentos, y Adivinador, en donde la maquina elige un número de una lista y tú intentas adivinarlo, ambos modos cuentan con 3 dificultades, las cuales aumentan la lista de números entre mayor sea.
